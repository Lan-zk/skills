## 第一部分：writing 技能迭代

### 决策 1：技能定位收窄

writing 技能只服务于**将用户的 idea 和素材转写为随笔性文章**。不同模式代表不同的认知切入方式，不是不同的体裁。

### 决策 2：砍掉 craft 和 snippet 模式

craft（叙事散文）和 snippet（微内容）模式均未经验证，且与"随笔"的核心定位不够匹配。保留 why-deep 和 observe 两个已经较为完善的模式。

### 决策 3：模式选择流程

- 优先问用户要原始想法/关注点（自由描述，不限格式）
- 技能基于描述给出**带倾向性的模式推荐 + 理由**
- 用户最终确认，技能不做静默自动选择
- 可选追问（信号不足时），追问不是门控，用户不答时技能兜底

### 决策 4：二选一 + 辅助机制

强制二选一（why-deep 或 observe），非主即辅。选定主模式后，另一个模式的技巧可作为辅助手段。

### 决策 5：AUTHOR.md 感知侧补充

observe 模式下作者锚点偏弱。原因是 AUTHOR.md 的判断型特质在 observe 里没有论证结构可以挂靠。解决方案：
- AUTHOR.md 追加"感知偏好"章节
- observe.md 补选材规则，将 AUTHOR.md 的感知偏好接入写作流程

### 决策 6：vibe-voice-overrides.md 合并

该文件只剩 observe 部分（snippet 已删除），合并进 observe.md 后删除。

### 决策 7：examples.md observe 示例

先用经典作家段落（汪曾祺、史铁生、鲁迅）过渡，后续替换成用户自己的成稿。

## 第二部分：AUTHOR.md 作为独立系统

### 决策 8：AUTHOR.md 不应只服务于 writing

用户明确提出：AUTHOR.md 应该是一个跨项目、跨工具、持续演进的人格记录。它可能基于任何一次对话、项目或经历而发生变更。

### 决策 9：三层结构

- **AUTHOR.md 本体**（HOT）：蒸馏后的精炼人格记录
- **候选池**（WARM）：原始观察和反思笔记
- **ARCHIVE**：已消费或过期的材料

### 决策 10：三种输入源

| 类型 | 产生者 | 权重 | 形态 |
|------|--------|------|------|
| C 原始观察 | AI 自动写 | 低 | 每次会话结束时 |
| B 反思笔记 | 用户自写 | 高 | 随时 |
| A 事件卡片 | AI 生成，用户确认 | 中 | 蒸馏对话中（中间产物） |

关键修正：A 不是输入源，是蒸馏过程的中间产物。

### 决策 11：晋升条件

原始观察满足以下条件之一才进入 AUTHOR.md：
- 跨场景重复 3 次以上
- 用户明确确认
- 用户主动提出

### 决策 12：蒸馏触发

- 定期（每周/每两周）
- 用户随时可主动发起

### 决策 13：蒸馏形态——对话式

不是审批式报告，而是一次对话。AI 提出观察，用户在对话中确认、修正、补充。AUTHOR.md 的更新从对话中自然产生。

借鉴 self-improving 技能（E:\File\self\github\self-improving-1.2.16）的晋升机制，但适配人格记录（narrative-based）而非行为偏好（rule-based）。

### 决策 14：跨工具兼容

蒸馏本身是一个工具无关的技能。每个工具只需：
1. 知道文件夹路径
2. 会话结束时能写一条原始观察到文件夹
3. 用户可在任一工具中发起蒸馏对话

先在 Claude Code 中跑通，后续通过各工具的 hook 扩展。

### 决策 15：观察边界

应记录：跨场景认知习惯、影响输出质量的特质、用户明确表达的价值观
不应记录：一次性情绪、环境强制行为、工具偏好、隐私、AI 猜测

### 决策 16：文件管理——Wiki 式独立文件

每条观察是独立 Markdown 文件，YAML frontmatter 带 status/tags，支持 `[[link]]` 双向链接。不依赖 Obsidian，纯 Markdown 兼容。

蒸馏时只加载 status: pending 的文件，token 效率高。

### 决策 17：蒸馏是增量精度提升

AUTHOR.md 的迭代不是行数膨胀，而是精度持续提高。新观察融入后可能修正、合并、替换现有内容，总行数保持稳定。

## 第三部分：AUTHOR.md 结构重组

### 决策 18：AUTHOR.md 与使用方式分离

AUTHOR.md 是纯粹的人格记录，不含任何使用方式。"如何用这份文件"由各技能自行定义。

从 AUTHOR.md 中剥离的操作化约束移入 writing skill 等技能的使用说明中。

### 决策 19：按哲学层级组织

参考以下研究材料：
- 研究计划书（E:\File\self\github\know-yourself\material\GPT-研究计划书.md）
- 深度自我认知报告优化（E:\File\self\github\writing-skills\深度自我认知报告优化.md）
- MISSION STATEMENT（E:\File\self\github\writing-skills\MISSION STATEMENT.md）

采用混合方案：哲学层级做骨架 + 每个层级标注对 AI 行为的实际影响。

### 决策 20：新结构

```
## 稳定底色（放在最前面，作为全篇压缩和索引）
## 世界观与现实感（本体论）
## 认识论（新增独立章节）
## 道德判断与价值秩序（含先问责再修复的顺序）
## 心智官能的层级关系（新增：理智 > 意志 > 情感）

## 感知偏好
## 内在张力与阴影（从附录升格为正式章节）
## 描述边界
```
