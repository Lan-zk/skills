## Design Context

### Users
Chinese developers and technical content creators who share GitHub open-source projects on WeChat Moments, Twitter, and newsletters. They want an at-a-glance, shareable card that communicates project authority and popularity in under 3 seconds.

### Brand Personality
**Editorial authority meets developer precision.** The card should feel like a premium tech magazine pullout — confident, structured, opinionated — not a generic dashboard widget or AI-generated gradient card. The personality is: **bold, typographic, print-inspired**.

### Aesthetic Direction
**Editorial newspaper/magazine masthead.** Think Bloomberg Terminal meets The Verge meets a premium developer newsletter. Uses a warm paper background (#faf9f7) with deep ink (#0f172a), a bold red-orange accent (#e8453c), and steel blue (#3d5a80) as a structural color. NOT dark mode, NOT blue gradients, NOT glassmorphism.

### Design Principles

1. **Typography is the hero.** Bold weight contrast (900 vs 400) with tight tracking. Monospace for labels and data creates technical authority. Display size jumps create hierarchy drama.
2. **Warm paper palette.** The card should feel like physical print — warm off-white, not clinical white. Three-color system (ink, accent, steel) over warm paper is more distinctive than any blue gradient.
3. **Editorial structure over decorative effects.** Masthead with ruled lines, bold left-edge accent on the repo card, strong top bar. No shadows on text, no glow effects, no decorative noise.
4. **Data-forward stat treatment.** Numbers are the primary visual interest. Bold weight, tabular nums, uppercase labels — they should look like they belong in a financial terminal.
5. **Social-first layout.** The 1080×1080 format is optimized for mobile feeds. Hierarchy must work at thumbnail size — masthead title and repo name must be legible even when the card is 200px wide.

### Anti-References (what to NEVER do)
- Blue-to-white gradient backgrounds
- Glassmorphism cards
- Dark mode with neon/glow accents
- Generic "AI slop" layouts (hero metric + gradient)
- Rounded rectangles with colored border on one side
- Emoji as icons
- Gradient text on headings or metrics
