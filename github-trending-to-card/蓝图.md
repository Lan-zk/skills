# 🧠 蓝图：GitHub Trending 榜单可视化卡片生成器 (OpenClaw Skill)

## 🎯 核心定位与业务上下文
* **核心目标 (Purpose)**：将 GitHub 枯燥的开源趋势数据，自动化转化为专供自媒体与内容运营分发的高颜值、高分辨率 PNG 图片。
* **运行环境 (Environment)**：部署于 OpenClaw 框架内的标准无状态 Skill。
* **架构解耦 (Architecture)**：本工作流仅负责“数据抓取 -> 结构化插槽组合 -> 网页渲染 -> 图片导出”

---

## ⚙️ 核心工作流节点定义

### 节点 1：入参路由与极速数据提取 (Data Scraper)

**技术栈：** `Python` + `requests` + `BeautifulSoup` (bs4)

- **执行逻辑**：
  1. 接收 Skill 入参 `time_range`、`language`（可选）以及 `spoken_language_code`（可选）。
  2. 动态拼接请求 URL：
     - 基础路径结合语言过滤，例如：`https://github.com/trending/{language}?since={time_range}&spoken_language_code={spoken_language_code}`
  3. 携带伪装的 `User-Agent` 发起 HTTP GET 请求获取 HTML 源码。
  4. 使用 `BeautifulSoup` 解析 DOM，精准定位前 10 个 `<article class="Box-row">` 容器。
- **数据清洗规则**：
  - **项目名称**：提取 `h2.h3 a` 的完整文本（如 `owner/repo`），去除多余空格。
  - **项目简介**：提取 `<p>` 标签内容。
    - **缺失兜底机制**：若该字段为空，则抓取该项目的主页地址（或 README 内容），将其提交给当下的调用模型进行语义分析，归纳出一句话的项目简介作为补充。
    - **智能翻译机制**：为了更好的中文阅读体验，将提取到的（或大模型归纳的）外文简介，提交给调用的大模型，让其以“IT 翻译专家”的角色，输出信达雅的中文简介。
  - **使用语言**：提取 `<span itemprop="programmingLanguage">` 文本；提取相邻的圆点节点的 `style` 属性中的 `background-color` (HEX 码)。
  - **总 Star 数量**：定位带有星号 SVG 的 `<a>` 标签，提取数字文本。
  - **新增 Star 数量**：提取带有 `float-sm-right` 类的 `<span>` 标签内容（例如 "150 stars today"），使用正则提取出纯数字和时间后缀。
- **节点产出**：一个包含 10 个对象的标准 JSON 数组。

### 节点 2：单卡片结构化组合 (Data Zoning)

**技术栈：** HTML/CSS/JS 固定模板 + 模板引擎 (如 `Jinja2` 或简单的字符串替换)

- **执行逻辑**：
  接收节点 1 的 JSON 数组数据与外部传入的固定模板代码，遍历项目列表，为**每一个项目**分别注入数据，生成独立卡片的完整 HTML 字符串。
- **单卡片 DOM 骨架定义 (Card Zone)**：
  - 放弃长图拼接，聚焦于单卡片（Single Card）模板渲染。每个卡片的 HTML 内预留固定的插槽变量，例如：
    - `<div class="repo-name">{name}</div>`
    - `<div class="repo-desc">{description}</div>`
    - `<div class="repo-lang"><span style="background-color: {hex};"></span>{language}</div>`
    - `<div class="repo-stars-total">{stars}</div>`
    - `<div class="repo-stars-new">{new_stars}</div>`
- **节点产出**：一个包含 10 个独立 HTML 字符串的数组（每个字符串对应一个单独项目的 HTML 代码）。

### 节点 3：单卡片渲染与 PNG 导出 (Rendering & Export)

**技术栈：** `Playwright` 或轻量级 HTML 转图方案 (如 `html2image`)

- **渲染方案说明**：
  为了将注入了参数的 HTML+CSS+JS 模板高质量地转为 PNG 单图，推荐使用**无头浏览器（Playwright/Puppeteer）**。它对现代前端布局（如 Flex/Grid）、CSS3 动画及高级视觉效果支持最为完美。
- **执行逻辑**：
  1. 在后台初始化一个全局的无头浏览器实例，以避免重复启动进程的开销。
  2. 遍历上一步生成的 10 个独立 HTML 字符串，对每一个项目执行：
     - 调用 `page.setContent(html_string)` 将单卡片 HTML 注入。
     - **视觉参数配置**：设定适合单卡片的固定视口宽度（如 `800px`），设备像素比 (Device Scale Factor) 设为 `2` 保证高分辨率渲染。
     - 等待页面渲染和 Web Fonts 加载完毕。
     - 针对单卡片的根级 DOM 元素（如 `page.locator('.card-container')`）执行精准截图。
  3. **替代方案 (轻量化)**：如果不需要极致渲染，可使用 Python 的轻量库 `html2image`（底层调用本地 Chrome 进程进行截图，代码极为简洁）。
- **节点产出**：包含 10 张高分辨率、单项目卡片 PNG 图片的数组（Buffer 或 Base64 编码流）。

## 📥 Skill 输入与输出规范 (I/O)

> **💡 调用与频率说明**：本 Skill 为纯无状态计算节点。**数据的抓取频率与缓存策略完全由调用该 Skill 的上游业务方决定**。Skill 内部不强制缓存逻辑，每次触发均执行实时抓取与渲染。

| 字段类型   | 参数名            | 类型   | 说明                                                | 默认值  |
| :--------- | :---------------- | :----- | :-------------------------------------------------- | :------ |
| **Input**  | `time_range`      | String | 榜单时间维度 (`daily`, `weekly`, `monthly`)         | `daily` |
| **Input**  | `language`        | String | (可选) 编程语言过滤，如 `python`, `javascript`      | -       |
| **Input**  | `spoken_language` | String | (可选) 自然语言过滤，如 `zh`, `en`                  | -       |
| **Output** | `trending_cards`  | Array  | 生成的 10 个项目的独立 PNG 图片数据数组 (Base64/流) | -       |
