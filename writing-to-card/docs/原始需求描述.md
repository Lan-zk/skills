# 原始需求描述

**项目目标**：
开发一个自动化工具（Skill），将长篇 Markdown 格式的文章自动封装并转换为一系列符合小红书排版规范的图片序列，以解决小红书平台不支持长图文发布的痛点。

**核心功能要求**：
1. **格式转换**：支持将 Markdown 文本输入转化为多张静态图片输出。
2. **样式对齐**：生成的图片在尺寸、字号、排版风格上需高度还原指定的参考图质感。
3. **内容区分**：需区分“首页（Cover）”与“正文（Content）”两种不同的排版模板。首页侧重标题展示，正文侧重长文本的舒适阅读。
4. **基础语法支持**：兼容并正确渲染 Markdown 的基础语法，包括简单标题、普通文本、加粗、斜体以及行内代码块。
5. **文件输出**：生成的多张图片需按顺序自动编号命名（无需在图片上绘制页码），便于直接批量上传至小红书。
