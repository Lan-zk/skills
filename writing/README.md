# writing

将 idea 和素材转写为随笔性文章。两种模式代表不同的认知切入方式。

## 核心定位

- `why-deep` 靠逻辑链下潜，掀前提、缩窄解释空间
- `observe` 靠感知校准推进，让细节和自我修正承担推进
- 使用 `AUTHOR.md` 作为作者底座，跨模式共享
- 文章要先经过作者本人，不能直接替素材代言
- 成稿默认只给 `1` 个标题

## 模式选择

优先问用户要原始想法 → 技能给出带倾向性的推荐 → 用户确认。详见 `references/modes/mode-selector.md`。

## 配套文件

| 文件 | 用途 |
|------|------|
| `SKILL.md` | 完整入口契约 |
| `AUTHOR.md` | 作者底座（判断侧 + 感知侧） |
| `references/modes/mode-selector.md` | 模式选择流程 |
| `references/modes/why-deep.md` | 论辩散文模式 |
| `references/modes/observe.md` | 随笔模式 |
| `references/voice-guide.md` | 跨模式文风规则 |
| `references/self-check.md` | 跨模式质检清单 |
| `references/examples.md` | 跨模式示例 |
