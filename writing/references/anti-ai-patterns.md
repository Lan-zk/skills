# AI 味识别与改写参考

本文档按症状分类，用于写作质检和中文重写阶段。
self-check 和中文重写阶段均引用此文件。

---

## 1. 踩雷词

零容忍。命中即重写整句。

| 踩雷词 | 为什么是 AI 味 |
|--------|----------------|
| 说白了 | 替读者下结论，假装亲切实则是在说"你听不懂我帮你翻" |
| 意味着什么 | 把判断包装成提问，但提问本身没有推进 |
| 本质上 | 未做论证就宣布已触及底层，通常是跳过了推理过程 |
| 换句话说 | 前面那句如果说不清，该改前面那句，而不是再绕一圈 |
| 不可否认 | 用语势强行封堵质疑，真正站得住的判断不需要这句话 |
| 值得注意的是 | 空降重要性声明，不解释为什么值得注意 |
| 需要强调的是 | 同上 |
| 毋庸置疑 | 否定质疑的姿态，不是论证 |
| 某种程度上 | 软化词，要么判断站得住就不加，要么站不住就不该下 |
| 不难发现 | 假设读者应该已经发现了，实际上是在替读者做认知动作 |
| 显而易见 | 同上 |
| 事实上 | 在中文里像英语 "in fact" 的直译，多数情况可删 |
| 众所周知 | 要么是真的众所周知（那就不必说），要么是借群体压人 |

**改写方向**：删掉这个词，看句子是否仍然成立。成立则该词多余；不成立则说明判断本身需要补强，而不是靠语气词撑。

## 2. AI 句式

高频重复的句式模板，一个句式全文最多出现一次。

### 2.1 "不是 A，而是 B"

- **识别**：用对比结构包装判断，一次两次是修辞，三次以上就是模板
- **改写方向**：直接说 B 是什么，不用先否定 A 再引出 B。或者把对比压进一个具体场景里，让读者自己看见区别

**AI 常说**：

> 这不是设计工具的升级，而是设计定义的重构。

**人怎么说**：

> 看到 DESIGN.md 之后，"工具升级"这个说法突然站不住了。

### 2.2 "不仅…而且…"

- **识别**：堆叠递进，两个判断之间没有真实推进，只是句式上并列
- **改写方向**：砍成两句短句，让第二个判断自己站出来

**AI 常说**：

> 它不仅能生成代码，而且能理解意图。

**人怎么说**：

> 它会写代码。但真正有用的不是写，是它知道你想做什么。

### 2.3 "一方面…另一方面…"

- **识别**：伪平衡，假装两边都照顾到了，实际是把一个判断藏在中立姿态后面
- **改写方向**：先说你站哪边，再用一句承认另一边的道理

### 2.4 "从 X 的角度来看"

- **识别**：视角切换像在做多角度展示，不是在推进判断
- **改写方向**：直接切换到那个视角的具体判断，不用先宣布"我要换个角度了"

### 2.5 "这提醒我们/这启示我们"

- **识别**：把一个观察硬拔成教训，读感像老师在总结课文
- **改写方向**：让观察本身足够有力，不需要再额外提炼教训

## 3. 概念打包

把复杂判断压缩成一句漂亮的话，看起来深刻，实际跳过了推理过程。

### 识别特征

- "这不是 X，而是 Y"（当 Y 是一个大词时）
- "它重新定义了/重构了/解构了 X"
- "它本质上是/根本上是 X"
- "一种新的 X 正在形成"
- "X 的底层逻辑是 Y"

### 改写方向

把打包拆开。先说出具体看到了什么，再让判断从具体对象里析出。

**AI 常说**：

> 这不是设计工具的升级，而是一种设计定义的重构。它将设计从视觉表达重新编码为机器可执行的协议层。

**人怎么说**：

> 我原来一直把这件事理解成设计工具升级。可看到 DESIGN.md 之后，这个解释突然站不住了。因为这里被改掉的，已经不只是画图方式，而是设计稿到底先写给谁读。

**[why-deep 侧重点]**：概念打包在 why-deep 里最常出现在每段结尾——用一句漂亮的话把段内推理打包收束。检查每段结尾，如果是"打包句"而非"推进句"，拆开或删掉。

**[observe 侧重点]**：概念打包在 observe 里常表现为对物象的过早命名——"鸭蛋象征乡愁""屏幕象征孤独"。把命名删掉，让物象自己承重。

## 4. 总结腔

出现在段末或文末，把已经说过的判断再收一遍。

### 识别特征

- "综上所述"、"总而言之"、"归根结底"
- "写在最后"、"最后我想说"
- 段末用一句把全段判断再打包说一遍
- 结尾段只是前文判断的摘要复述

### 改写方向

结尾要么把问题再往前推半步，要么停在真实仍有重量的未解处。如果删掉结尾段全文不受影响，直接删。

**AI 常说**：

> 总而言之，设计稿的角色正在经历一次根本性的转变。

**人怎么说**：

> 如果设计稿首先不是给人看的，而是给机器读的，那今天很多默认动作都得重写。这个问题我现在还没有完整答案，但我已经很难再把设计稿只当成一张图了。

**[why-deep 侧重点]**：why-deep 的结尾必须比前文更深一步，不能是摘要回收。如果结尾只是把前文的判断换词再说一遍，整段删。

**[observe 侧重点]**：observe 的结尾优先回到开头的具体对象（物象、场景、动作），让它带着新的重量重新出现，而不是给全文做总结。

## 5. 翻译腔

中文写出来像从英文翻译过来的。

### 识别特征

- "进行 + 动词"（进行讨论 → 聊，进行操作 → 点击）
- "实现 + 名词"（实现功能 → 做到）
- "通过 X 来 Y"（通过…来提升…）
- "被 X 所 Y"（被时代所淘汰）
- 嵌套从句：一句话里套了三层"的"或两个以上"which 式"定语
- 被动句式过多（"被认为是""被称为"）
- "当…的时候"开头

### 改写方向

- 从句拆开，嵌套展平
- 主语不必逐句给，汉语靠意合
- 能两个字说的不用四个字
- 动宾搭配用中文里最自然的那种
- 被动句改成主动句或无主语句
- 翻回英文再翻回中文还是原样 → 八成翻译腔，重写

**AI 常说**：

> 通过充分利用这一工具的能力，开发者可以显著提升工作效率。

**人怎么说**：

> 用好这个工具，开发速度快不少。我测下来，每个项目平均省三五个小时。

## 6. 空泛大词

用大词代替具体判断。

### 识别特征

- "显著提升"、"大幅改善"、"充分优化"（不给数字）
- "许多"、"一些"、"大量"（不给具体数量）
- "越来越 X"（什么在变、变了多少、什么时候开始变的？）
- "不断进化"、"飞速发展"、"日新月异"
- "深入探讨了"、"全面分析了"、"系统地梳理了"
- "值得深入思考"（什么值得思考？为什么？）

### 改写方向

用具体数字、具体对象、具体时间替换。如果没有具体信息，缩小判断范围，不要用大词撑场面。

**AI 常说**：

> 经过一段时间的使用，发现它在很多方面都表现优秀。

**人怎么说**：

> 用了两周。最明显的变化是，之前要三天的项目，现在一天半就搞定了。

---

## 7. 层级宣告

用显性层级词推读者，而不是让层级在推进中被感受到。

### 识别特征

- "第一层/第二层/更深层"
- "再深入一步"、"更深地说"、"最深的一层是"
- "更根本的问题是"、"再往下看"
- "表面上看…但实际上…"（连续出现）

### 改写方向

层级应该体现在认知位移里，不是在层级提示词里。删掉层级词，检查读者是否仍能感到"被带深了"。如果能，层级词多余；如果不能，说明推进本身不够，需要补内容而不是补提示。

**AI 常说**：

> 表面上看这是一个效率问题。但更深层地看，这其实是一个定义权的问题。

**人怎么说**：

> 我一开始以为这只是效率问题。可问题一旦改成"谁在定义约束"，讨论就变了。

**[why-deep 侧重点]**：why-deep 的四层下潜（现象→解释→前提→重构）是后台组织模型，不是正文的显性标签。正文里出现"第一层""第二层"时，默认删掉。

## 8. 态度中立/安全

不敢下判断，用中立姿态替代立场。

### 识别特征

- "既有优点也有缺点"（然后两边各说一半，什么都没说）
- "具体取决于实际情况"（判断的退缩版）
- "可能"、"或许"、"在某些情况下"（过量出现）
- "每个人看法不同"（在需要判断的地方拒绝判断）
- "这或许就是 X 的意义所在"（空心升华）

### 改写方向

该下判断就下判断。可以承认不确定性，但不确定不等于不敢说。"大概 70%"比"可能"诚实。"我觉得 X，但不一定对"比"各有道理"有信息量。

**[why-deep 侧重点]**：why-deep 的判断是被逼出来的，但"被逼出来"不等于"不确定"。到了该封口的地方，判断要硬。

**[observe 侧重点]**：observe 允许悬置，但悬置必须有真实重量——旧解释为什么成立、在哪里裂开、为什么还不能收束。不是"这个问题很复杂我也没有答案"。

---

## 9. 故作姿态

语言先让人注意到"写得很用力"，而不是先让人进入问题。

### 识别特征

- 最后一句单拎出来像故意留余味
- 某个词比问题本身更显眼（"遮蔽""迫使""不可逆转""命运般的"）
- 句子写得像可引用的金句
- 连续冒号定义，像在搭建概念框架
- "正是在这里，我意识到"（把认知动作本身当成内容）

### 改写方向

词不要先于问题显眼。如果一句话先让你意识到"这句写得很用力"而不是先把你带进问题，换掉。

**AI 常说**：

> 正是在这个裂缝中，我们窥见了某种更真实的秩序。

**人怎么说**：

> 到这里，问题已经不是原来那个问题了。

**[observe 侧重点]**：observe 里最常出现的姿态是"灵魂升华腔"——把普通经验快速拔到生命、时代、人性层面。没有事实现场、异常细节和自我校准，就不允许升维。
