# 文风指南（通用）

本文档包含跨模式通用的文风规则。
模式专属约束见 `modes/why-deep.md` 和 `modes/observe.md`。

=====================================================================
一、总边界
=====================================================================

- 允许有人味，但不允许靠口头禅假装有人味
- 可以更口语，但不能把主线聊散
- "我"要服务判断，不是服务自我表演

=====================================================================
二、六条主规则（通用）
=====================================================================

规则 1：先推进，再解释

- 不要一上来就总结、定义、命名
- 先让读者看到问题是怎么卡住的，再给出你的判断
- 如果一句话只是把后文要说的内容提前包装出来，优先删掉

规则 2：转场像人在带问题，不像报告在切章节

- 转场句的作用是把读者继续往下带，不是提醒读者"现在进入下一部分"
- 比起"首先""其次""更进一步"，优先用更自然的带路句
- 好转场通常会顺手改写问题，而不是只改写说法

规则 3：可以更口语，但口语只是一层表面形式

- 口语化不是多用语气词，不是刻意断句，不是整篇都写得很碎
- 真正有用的口语化，是让句子更像当下在推进，而不是像已经收拾好的讲稿
- 关键转折处可以更短、更硬一点，别的地方还是要稳

规则 3.5：词不要先于问题显眼

- 如果一个词先让人注意到"写得很像在写"，而不是先让人进入问题，优先换掉
- 像"遮蔽""迫使""不得不承认""真正值得"这类词，不是禁词，但它们很容易把句子写出方法腔和姿态感
- 词本身没问题，不代表放在这里就对。判断标准是：这个词是在推动问题，还是在提醒读者"我正在认真写作"

规则 4：私人视角不是自我讲述，是把问题接回作者位置

- 私人视角的作用，不是讲自己经历过什么，而是交代"我为什么偏偏会从这里起疑"
- 作者的职业位置、经验摩擦、价值排序，都可以进入正文
- 但一旦开始变成自我介绍、履历展示、情绪流水账，就偏了

规则 5：判断力不是居高临下，是承认自己被什么说服了

- 不要把判断写成裁判腔
- 更好的写法，是承认自己原来怎么理解，后来又是被什么具体东西打动、打断、说服
- 这会让文章更像真实判断，而不是预设立场后的演讲

规则 5.5：少用"我们"替读者站位

- "我们"不是默认主语。它天然带有绑定感，容易让作者和读者在文本里被预先绑成同一立场
- 除非真的是公共动作、共享常识或必须共同承担的现实处境，否则优先用"我"、无主语句，或直接写对象本身
- 更好的状态不是"我们一起这么想"，而是"我这样想，你读完后自己决定是否跟上来"

=====================================================================
三、转场词清单（通用）
=====================================================================

这些不是模板，而是常用动作。

自然推进：

- 可问题在于
- 麻烦也在这里
- 到这里，问题其实已经变了
- 这时候再看
- 回到这里
- 但光这么解释还不够
- 事情是从这里开始不一样的

扣主线句：

- 说到底，这里真正被改掉的不是动作本身，而是它背后的前提
- 所以问题已经不再是表面这个问题了
- 这也是为什么我会一直卡在这里
- 说回主线，这里改掉的其实是对象边界

私人视角连接：

- 我是做开发的，所以我会先警惕这一层
- 如果我只站在产品视角看，这个解释当然成立
- 我真正开始不安，是在看到这里的时候
- 这块让我很难再按原来的方式理解它

=====================================================================
四、口语化推进（通用）
=====================================================================

推荐方向：

- 少一点"完整解释"，多一点"当下推进"
- 少一点概念包装，多一点对象、动作、场景
- 少一点漂亮收束，多一点真实停顿

可接受的口语化句式：

- 这个解释很顺，但不够
- 我一开始也这么想
- 我原来把这里看轻了
- 真正让我卡住的反而是这个
- 到这一步，其实已经不是原来那个问题了

不建议的做法：

- 整篇大量使用语气词、感叹号、省略号
- 为了去 AI 味，故意写错、故意写散、故意堆口癖
- 机械模仿某种强叙事腔和高频口语词组

=====================================================================
五、AI 味重段落怎么返工
=====================================================================

常见症状：

- 连续命名概念
- 连续下定义
- 每段都收得刚刚好
- 像已经想完了，不像正在想通
- 某个词比问题本身更显眼
- 最后一句像故意留余味
- 显性标层太多，像在展示思路骨架
- 结尾像"写在最后"的摘要回收

返工步骤：

1. 删掉一句最像结论包装的话
2. 补一句作者为什么会卡在这里
3. 找一个更具体的对象或动作把抽象词落下去
4. 用一句扣主线句把它拉回主问题
5. 检查是不是用了不必要的"我们"，把它改回更开放的主语
6. 检查是不是在用层级词硬推读者，把层级提示改回自然推进

目标：

- 把"模型整理后的答案"改回"作者正在形成的判断"
