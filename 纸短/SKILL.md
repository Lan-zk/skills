# 纸短 · 侨批文言转换

将现代白话转写为侨批风格——半文半白，克制深情，以物载情。

## 工作流程

1. **读取用户原文**，理解：
   - 写信人与收信人的关系（夫妻、父子、兄弟、朋友、同乡）
   - 核心情感与信息（思念、报平安、愧疚、喜讯、家事、商务）
   - 用户是否有特定时代/地域/方言区设定

2. **提取关键信息**，映射到侨批要素：
   - 银钱事项 → 番银数额、用途
   - 生活近况 → 简述，一两句带过
   - 家乡关切 → 具体物件、人名、地名
   - 情感 → 转化为具体细节，不直接抒情
   - 喜讯 → 克制的骄傲，用事实说话
   - 家务事 → 务实口吻，远程管理语气

3. **参照 `references/style-guide.md`** 选择：
   - 称谓（开头）与落款（结尾）
   - 核心侨批词汇替换白话
   - 文言句式重组句子
   - 方言区用词差异（默认潮汕，用户可指定）

4. **参照 `references/examples.md`** 校准：
   - 节奏是否对（短句为主，四字句为骨架）
   - 情感是否克制（最痛的话只说半句）
   - 是否有现代白话残留
   - 基调是否匹配原信（不把喜讯写成悲剧，不把家事写成抒情）

5. **输出侨批全文**，附简要说明转换要点

## 核心规则

### 以物代情
不写"我想你"，写他记得门前的蕉树。不写"我很苦"，写"每日辛苦，然所得稍丰"。实物比形容词诚实。

### 银钱即情感
侨批的核心功能是汇款。银数、汇款方式、用途说明本身就是情感表达。银数减少暗示处境艰难，银数增加是报答之心。

### 短句为骨
三到八字为主，四字句出现频率最高。不超过十二字的长句。句式参照文言但不追求纯古文——侨批是实用文体，不是文学。

### 留白
最重的情感只写半句："离家愈久，愈不敢忆家"。后面是空白，让读者自己去填。

### 代笔变体
当设定为第三人代笔时：
- 语气更客气、更疏远
- 借他人之口转述情感（"酒后常言：'此生最负淑柔'"）
- 代笔者偶尔流露自己的感慨

## 自检清单

- [ ] 称谓是否匹配关系
- [ ] 落款是否匹配情感强度
- [ ] 是否有现代白话句式残留（"我非常…"、"希望你…"、"感到…"）
- [ ] 情感是否克制（全文直接抒情不超过两处）
- [ ] 是否有具体物件/细节承载情感
- [ ] 句子长度是否以短句为主
- [ ] 基调是否匹配原信（不是所有侨批都是悲剧）
- [ ] 是否过度依赖单一叙事模式（如有风格参照集，仅作风格参照，不限制叙事结构）
