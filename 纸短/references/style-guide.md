# 侨批文言风格指南

## 一、何为侨批

侨批，又称"番批"，是近代海外华侨寄回国内的家书与汇款合一的信件。潮汕、闽南、客家地区最为典型。侨批不是文学创作，而是真实生活缝隙里的文字——字字克制，句句带土。

关键特征：
- 文言为骨，白话为肉，不追求纯正古文
- 叙事极简，情感极重
- 细碎家事与宏大离愁共存
- 钱银数字是核心内容之一

### 侨批的多样性

侨批不是单一的情感模板。它覆盖所有真实人际关系中的通信需求：

| 场景类型 | 典型内容 | 情感基调 |
|----------|----------|----------|
| 报平安 | 抵达、谋生、近况 | 平实、安慰 |
| 寄银 | 银数、用途、承诺 | 务实、担当 |
| 家事关切 | 子女教育、田产、修屋 | 操心、远程管理 |
| 喜讯 | 生子、婚嫁、考学 | 欢喜、克制的骄傲 |
| 告别/托付 | 病重、遗言、身后事 | 沉重、留白 |
| 代笔 | 第三人转述 | 疏离中见真情 |
| 商务寒暄 | 货源、行情、托带物品 | 客气、实际 |

不要让"悲剧侨批"垄断你对这一文体的理解。喜讯信、报平安信、商务信同样真实。

### 地域差异

侨批风格因方言区而异，转换时可根据用户设定选择：

| 方言区 | 用词特点 | 句法倾向 |
|--------|----------|----------|
| 潮汕 | 番畔、营生、目汁、食、行 | 四字句密集，文言比例最高 |
| 闽南 | 番客、过番、趁钱（赚钱）、厝（房子） | 文白夹杂更明显，闽南语词汇更多 |
| 客家 | 过番、转屋下（回家）、细人仔（小孩） | 句式稍长，客家口语痕迹重 |

默认使用潮汕风格（最为典型）。用户可指定方言区。

## 四、句法规范

### 文言骨架

侨批不追求纯粹文言，而是"半文半白"——以文言句式为骨架，夹入方言白话。

**典型句式：**

```
吾已平安抵暹。          ← 文言主干
水程虽远，幸无他虞。    ← 四字对仗
此间炎蒸，与唐山大异。  ← 对比句式
```

**节奏规律：**
- 短句为主，三到八字最佳
- 长句不超过十二字
- 四字句出现频率最高，构成呼吸节奏
- 避免现代标点的长句复合结构

### 转折与连接

| 功能 | 用词 |
|------|------|
| 转折 | 然、但、无奈、岂料 |
| 因果 | 故、是以、遂 |
| 时间 | 前日、今岁、年来、忽忽 |
| 假设 | 倘、若、万一 |
| 让步 | 虽、纵、虽则 |
| 递推 | 愈……愈……、不觉…… |

### 否定与疑问

```
未知可曾收到？        ← "不知有没有收到"
毋庸悬念。            ← "不用担心"
恐难久持。            ← "怕是撑不久了"
勿令忘本。            ← "别让他忘了根"
```

## 五、情感节制

侨批最核心的风格特征是**节制**。但这不意味着只能写悲伤——喜讯、骄傲、愤怒同样要克制。节制是修辞纪律，不是情感限定。

### 节制手法

1. **以物代情**：不直说想念，说"门前蕉树，可勿令鸡鸭践坏"——他记得那棵树。
2. **以事代情**：不直说辛苦，说"每日辛苦，然所得稍丰"——辛苦一笔带过，重点是还能挣到钱。
3. **以钱代情**：汇款数字本身就是情感表达。银数变化暗示处境变化。
4. **以物传承**：金戒指、照片、旧皮箱——实物比语言更诚实。
5. **留白**：最痛的话往往只写半句。"离家愈久，愈不敢忆家"——后面是空白。
6. **借他人之口**：代笔信中，借第三者转述比直说更重。
7. **自嘲**："莫学你阿爸，一辈子在番畔做工"——骄傲与心酸共存。

### 禁止

- 不用现代抒情句式（"我好想你"、"我的心碎了"）
- 不用排比煽情
- 不用感叹号堆砌
- 不用抽象情感词的直接陈述（"我感到无比悲伤"）
- 不用比喻夸张
- 不限于悲剧——侨批也有欢喜、务实、甚至愤怒

### 允许

- 偶尔的白话口语痕迹（"银虽微薄"）
- 方言词汇自然混入
- 具体物件承载情感（金锁、照片、旧皮箱）
- 极少量的直接抒情（"不觉泪下"、"思之痛极"）——但须克制，全文不超过一两处
- 喜讯中的骄傲（"为父虽远在千里，亦觉面上有光"）
- 家务事中的务实口吻（"田亩之事，兄长全权处置即可"）

## 六、结构模板

一封侨批的基本结构：

```
[称谓]：

[近况交代——一两句，说平安或不安]

[银钱事项——寄了多少，做什么用]

[家事关切——问家里的具体事]

[情感收束——克制的一两句]

[落款]
```

### 变体

**好消息信**可调整顺序：喜讯 → 银钱 → 期望 → 收束

**家事信**可侧重中间：近况 → 事务详情（田产、修屋、子女）→ 银钱 → 收束

**长信变体**当信件时间跨度大、情感累积重时，可松动结构：回忆往昔、引述他人、多层转折、真相揭露。

## 七、常见错误

| 错误 | 问题 | 修正 |
|------|------|------|
| "我非常想念你" | 现代白话，无节制 | 删，或改为具体细节 |
| "啊，故乡！" | 抒情腔 | 改为"故园月色，与旧时应无异耳" |
| "我的心情非常沉重" | 抽象情感 | 删，用事态本身说明 |
| "希望你一切顺利" | 现代祝福语 | 改为"望善自珍重" |
| "我很抱歉不能回去" | 直接道歉 | 改为"月下思之，愧甚" |
| 使用"您" | 侨批无此用法 | 用"汝"或具体称谓 |
| 使用"的"过密 | 白话助词破坏节奏 | 换文言结构或直接省略 |
| 全篇只写悲伤 | 把侨批等同于悲剧 | 侨批也写欢喜、务实、日常 |
| 称谓/落款不匹配关系 | 称谓体系混乱 | 查本指南称谓表 |
| 现代事物无转化 | "手机""公司"等直入 | 转化为时代语境或用功能描述替代 |
